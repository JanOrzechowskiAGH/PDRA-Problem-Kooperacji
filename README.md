# PDRA-Problem-Kooperacji
---

To repozytorium zawiera rozwiązany problem kooperacjnej eksploracji wygenerowany na potrzeby zajęć 'Problemy Decyzyjne Robotów Autonomicznych'
## Struktura projektu

W głównym katalogu znadują się główne pliki projektu:
```bash
├── PDRA-Problem-Kooperacji
│   ├── des_model.py               - model DES (środowisko + roboty + ograniczenia)
│   ├── candidate_pareto.py        - raportowalny zbiór kandydatów i Pareto
│   ├── enumerate_pareto.py        - pełniejsza enumeracja
│   ├── out                        - Wyniki uruchomienia algorytmu
│   │   ├── candidates.csv         - zbiór wszystkich kandydatów
│   │   ├── pareto_candidates.csv  - zbiór Pareto
│   ├── README.md      
│   ├── report.md                  - Wygenerowany raport
│   └── requirements.txt           - Wymagane biblioteki Python
```
